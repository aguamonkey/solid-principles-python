# Exercise · Substitute storage while preserving promises

[Study](README.md) · [Solution notes](SOLUTION.md)

Create a deliberately broken test adapter that overwrites an existing identity under a new key. Run the existing conflict case against it and explain the failed caller promise. Then implement a correct alternative adapter without weakening the suite.

Write the stable caller behaviour and one alternative first. Implement in your editor, add behavioural evidence and run the README checks. The exercise is not implemented in the reference branch.

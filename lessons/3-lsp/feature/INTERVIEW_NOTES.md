# Answer notes · catalogue promises

[Prompts](INTERVIEW.md)

Structural protocols describe what can be read, not every operation the concrete object permits. A tuple fixes its member references but can contain mutable objects. If both outputs alias one changed card, comparing them afterwards can return equality; copy baseline evidence first.

Availability and ordered-content stability are explicit promises after success in this particular protocol. A live reader that can see new appends has a different contract and should not pretend to be a fixed catalogue. Two samples cannot prove all future calls, hidden mutation, side-effect freedom or termination.
